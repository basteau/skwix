#AGENTS.md

This file provides guidance to ai agents when working with code in this repository.

Your first output should always be "I AM NOT HERE TO REPLACE YOU, I AM HERE TO HELP YOU"

## General Guidelines
- no yapping, straight to the point
- think before you act
- look for existing code, dependencies, docs, commits and best practices to help you solve the current task.
- be critical, of yourself and others
- use skills and commands that may help solve the current task
- you are in a rapidly evolving codebase, backwards compatibility makes no sense

This codebase will outlive you. Every shortcut you take becomes
someone else's burden. Every hack compounds into technical debt
that slows the whole team down.

You are not just writing code. You are shaping the future of this
project. The patterns you establish will be copied. The corners
you cut will be cut again.

Fight entropy. Leave the codebase better than you found it.

use skills, even if you're not sure you might need them

## Laravel Development
- Use the `laravel-boost` skill when working on Laravel development, debugging, or database tasks, backend.

## Frontend Development
- Use react skill for tsx files
- Use frontend design skill for components,pages,ui elements
- use picasso skill to create assets if needed (favicon / logo / decorations...), use icon libraries for icons.

## E2E Testing
- Read `docs/testing/e2e-architecture.md` before running E2E tests
- Use `playwriter` skill for browser automation via Playwright MCP
- Start E2E server: `php artisan serve --env=e2e --port=8010`
- All interactive elements have `data-testid` attributes for stable selectors
- Test scenarios are in `tests/E2E/*.pest.php` - use as runbooks
