# Backend Review Checklist

- [ ] **Models & Relationships** - `app/Models/` - Eloquent models, relationships, scopes, accessors/mutators
- [ ] **Controllers** - `app/Http/Controllers/` - Request handling, response logic, controller organization
- [ ] **Routes** - `routes/web.php` - Route definitions, grouping, middleware assignment
- [ ] **Middleware** - `app/Http/Middleware/` - Request/response filtering, authentication guards
- [ ] **Form Requests & Validation** - `app/Http/Requests/` - Input validation, authorization rules
- [ ] **Actions** - `app/Actions/` - Single-responsibility action classes, business logic
- [ ] **Services** - `app/Services/` - Service layer, external integrations, complex operations
- [ ] **Database** - `database/migrations/`, `database/seeders/` - Schema design, indexes, seeders
- [ ] **Mail** - `app/Mail/` - Email templates, notifications, mail configuration
- [ ] **Configuration & Auth** - `config/` - App config, authentication setup (Fortify), service bindings
